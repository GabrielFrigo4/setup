# 📟 Common Modern CLI Utilities

> Receitas universais em POSIX Shell para instalação de utilitários essenciais de terminal.

---

## 🎯 Finalidade

Esta pasta centraliza a instalação de ferramentas modernas de linha de comando: **bat**, **eza**, **fd**, **ripgrep**, **zoxide** e **fastfetch**.
