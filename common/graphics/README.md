# 🎮 Common GameDev & Graphics Libraries

> Receitas universais em POSIX Shell para desenvolvimento de jogos, multimídia e gráficos interativos no Host.

---

## 🎯 Finalidade

Esta pasta centraliza receitas universais para bibliotecas de desenvolvimento de jogos e interfaces multimídia (**SDL3**, ecossistema **SDL3_image**, **SDL3_net**, **SDL3_ttf**, **SDL3_mixer**, **SDL_gpu_shadercross**, **GLFW** e toolchains WebAssembly **Emscripten**).

> ℹ️ **Automações Windows:** As receitas equivalentes para Windows residem em [`../../windows/msys2/graphics.sh`](../../windows/msys2/graphics.sh) e [`../../windows/native/gamedev.cmd`](../../windows/native/gamedev.cmd).
