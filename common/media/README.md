# 🎬 Common Media Processing Tools

> Receitas universais em POSIX Shell para manipulação e processamento de áudio, vídeo e imagem.

---

## 🎯 Finalidade

Esta pasta centraliza a instalação de ferramentas essenciais de multimídia: **FFmpeg**, **ImageMagick** e **yt-dlp**.

---

| :----------------- | :---------------------------------------------------------- | :------------------------------------------ |
| [`cli.sh`](cli.sh) | Ferramentas de processamento de mídia (FFmpeg, ImageMagick) | Linux / FreeBSD / macOS / WSL / MSYS2 / Win |
