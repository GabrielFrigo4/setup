# 🛡️ Common Security & Analysis Tools

> Receitas universais em POSIX Shell para ferramentas de análise binária, depuração e segurança.

---

## 🎯 Finalidade

Esta pasta centraliza ferramentas de auditoria e inspeção de código e binários: **LLDB**, **Valgrind**, **Strace** e **Radare2**.
