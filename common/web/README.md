# 🌐 Web Browsers

> Receitas multiplataforma para instalação de navegadores web.

---

## 🎯 Finalidade

Provisiona navegadores web modernos de forma padronizada através do gerenciador de pacotes nativo de cada sistema operacional suportado.

---

## 📂 Catálogo de Arquivos

| Arquivo                      | Plataforma                        | Descrição                                                |
| :--------------------------- | :-------------------------------- | :------------------------------------------------------- |
| [`browsers.sh`](browsers.sh) | Linux / FreeBSD / macOS / Windows | Instala navegadores web principais no sistema hospedeiro |

---

## 🚀 Como Usar via GitHub (Zero-Clone)

Instalar navegadores web no sistema hospedeiro:

```sh
curl -fsSL [https://raw.githubusercontent.com/GabrielFrigo4/setup/main/common/web/browsers.sh](https://raw.githubusercontent.com/GabrielFrigo4/setup/main/common/web/browsers.sh) | sh
```
