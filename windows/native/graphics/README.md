# 🖥️ Windows Native Graphics — Modelagem & Criação 3D

> Receitas modulares de automação para provisionamento de ferramentas gráficas e 3D no Windows.

---

## 🎯 Finalidade

Esta pasta reúne scripts dedicados para instalação e configuração de ferramentas de criação 3D e computação gráfica no ambiente Windows nativo (sem virtualização), utilizando o Windows Package Manager (`winget`).

## 🚀 Como Executar

Abra o Prompt de Comando (`cmd.exe`) ou PowerShell com privilégios de Administrador e execute:

```cmd
blender.cmd
```
